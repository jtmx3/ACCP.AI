# ACCP.AI — نموذج أولي عربي لمقابلة الوقائع الإلكترونية

تطبيق ويب محلي باللغة العربية لتوثيق إفادة المستخدم عن واقعة إلكترونية، طرح سؤال واحد مناسب في كل مرة، حفظ الإجابات مع مصدرها وحالتها، عرض فرز أولي قابل للتفسير، ثم إنشاء ملخص Markdown يراجعه المستخدم ويؤكده.

> **تنبيه:** هذا نموذج أولي تجريبي وليس خدمة طوارئ أو مشورة قانونية أو بلاغًا رسميًا. الدرجات قواعد فرز تجريبية وليست احتمالات أو إثباتًا. لا تُدخل بيانات شديدة الحساسية في نشر عام.

## الموجود في هذا الفرع

- واجهة RTL عربية متجاوبة، ومحادثة تكيفية، ووضع منفصل لأسئلة الإرشاد.
- حالات مستقلة للإفادة المذكورة، والنفي، وعدم المعرفة، وعدم التذكر، ورفض الإجابة، والتعارض.
- حفظ SQLite مع رمز عشوائي خاص بكل جلسة، ورقم إصدار لمنع الكتابة فوق حالة أحدث.
- استكمال الجلسة، مراجعة الملخص، تأكيد إصدار محدد، وتنزيل تقرير Markdown.
- استرجاع محلي من مصادر موثقة ومقيدة جغرافيًا، مع استشهادات وعدم اختلاق مصدر عند غياب تطابق كافٍ.
- افتراضيًا لا يُستخدم نموذج خارجي. خيار OpenAI-compatible اختياري، ويحتاج موافقة مستقلة لكل سؤال؛ يرسل السؤال الحالي ومقتطفات المصادر فقط، وليس سجل المقابلة تلقائيًا.

المعمارية والسياسة والقيود مفصلة في [`docs/HANDOFF_AR.md`](docs/HANDOFF_AR.md)، وقواعد الفرز في [`docs/POLICY_AR.md`](docs/POLICY_AR.md)، والاختبارات في [`docs/VALIDATION_AR.md`](docs/VALIDATION_AR.md).

## التشغيل المحلي

يتطلب Python 3.10 أو أحدث. من جذر المستودع:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
set -a
. ./.env
set +a
python -m app.rag --reindex
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

افتح <http://127.0.0.1:8000>. الافتراضي هو قواعد محلية؛ لا حاجة لمفتاح API. تُنشأ قاعدة البيانات تلقائيًا في `data/accp.sqlite3`، وهي مستثناة من Git لأنها قد تحتوي على معلومات شخصية. أوقف الخدمة قبل حذف قاعدة البيانات. لا تشغّلها على واجهة عامة أو شبكة مشتركة دون إضافة مصادقة وإعداد نشر آمن.

## مزود النموذج الاختياري

يبقى `MODEL_PROVIDER=rules` هو الافتراضي. لتفعيل نموذج متوافق مع OpenAI، اضبط المتغيرات التالية في البيئة بعد توفير مفتاح من المشغّل:

```bash
MODEL_PROVIDER=openai-compatible
MODEL_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4o-mini
MODEL_API_KEY=...       # لا تضعه في Git أو في الواجهة
MODEL_TIMEOUT_SECONDS=15
```

إذا تكوّنت الإعدادات، تظهر خانة موافقة عند استخدام «وضع السؤال للبوت». تُرسل فقط صياغة السؤال الحالية ومقتطفات المصادر المسترجعة؛ إذا كتبت معلومة شخصية داخل السؤال فستُرسل معه. لا يرسل التطبيق سجل المحادثة أو حقائق المقابلة تلقائيًا. عند انقطاع المزود يرجع التطبيق إلى الرد المحلي. اختبر ذلك محليًا قبل ضبط أي مزود حقيقي، وتحقق من سياسة الاحتفاظ لدى المزود.

## الاختبارات وتحديث المصادر

```bash
python -m unittest discover -s tests -v
node --check static/app.js
```

لتحديث قاعدة المعرفة: عدّل `data/knowledge.json`، وتحقق من بيانات كل مصدر ثم نفّذ:

```bash
python -m app.rag --reindex
```

هذا النموذج يستخدم بحثًا معجميًا بسيطًا داخل JSON ولا ينشئ فهرس embeddings. لا يتضمن قاعدة مصادر أردنية حاليًا؛ لا تظهر إرشادات محلية أردنية عند اختيار `JO` أو ترك الاختصاص فارغًا. تفاصيل المصدر وتقييم الجاهزية في وثائق `docs/`.
