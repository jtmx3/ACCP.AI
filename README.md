# ACCP.AI — نموذج أولي عربي لمقابلة الوقائع الرقمية

تطبيق ويب عربي RTL لتنظيم إفادة المستخدم عن واقعة رقمية. يطرح سؤالًا واحدًا في كل مرة، ويحفظ الوقائع مع اقتباساتها ومصادرها، ويدعم التصحيح والاستكمال، والفرز التجريبي القابل للتفسير، ثم مراجعة الملخص وتأكيد إصداره وتصديره إلى Markdown وJSON.

> **تنبيه:** هذا نموذج أولي للتجربة، وليس خدمة طوارئ أو استشارة قانونية أو بلاغًا رسميًا. درجات الفرز تجريبية وليست احتمالات أو إثباتًا. لا تستخدمه لحالات حقيقية عالية الحساسية أو للنشر العام دون مراجعة وأمن واعتماد مناسب.

## ما يتضمنه هذا الفرع

- واجهة RTL عربية متجاوبة، مقابلة تكيفية، حفظ واستكمال، تصحيح وإضافة، تأكيد إصدار محدد، وتصدير التقرير.
- حالات متميزة للإفادة والنفي وعدم المعرفة وعدم التذكر والامتناع والتعارض. لا يُستنتج وقوع النشر من التهديد به، ولا اختراق الحساب الأصلي من وجود حساب منتحل.
- لا يطرح سؤال الخطر المباشر استباقيًا؛ ويُفحص كل دور محليًا لمؤشرات عنف جسدي وشيك، دون خلط الابتزاز أو التهديد الرقمي وحده بالخطر الجسدي.
- SQLite محلي مع رمز منفصل لكل جلسة و`expected_revision` لمنع الكتابة على إصدار قديم.
- استرجاع مصادر محلي مصنف جغرافيًا يشمل أستراليا والولايات المتحدة والأردن. وجود مصدر لا يثبت انطباقه على واقعة فردية.
- وضع تشغيل افتراضي بالقواعد فقط (`MODEL_PROVIDER=rules`). الخيار الآخر هو Ollama على loopback المحلي؛ لا يدعم التطبيق إرسال بيانات الحالة إلى خدمة نموذج بعيدة.
- توليد سؤال متابعة محلي اختياري وجلسي، منفصل تمامًا عن موافقة إرسال كل رسالة للاستخراج أو الإجابة الإرشادية.

الحدود المعمارية في [`docs/HANDOFF_AR.md`](docs/HANDOFF_AR.md)، سياسة الفرز في [`docs/POLICY_AR.md`](docs/POLICY_AR.md)، سجل التحقق وحدوده في [`docs/VALIDATION_AR.md`](docs/VALIDATION_AR.md)، ودليل تشغيل Ollama في [`docs/PROVIDER_SETUP_AR.md`](docs/PROVIDER_SETUP_AR.md).

## التشغيل المحلي — Linux/macOS

يتطلب Python 3.10 أو أحدث. من جذر المستودع:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
set -a
. ./.env
set +a
python -m app.rag --reindex
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

افتح <http://127.0.0.1:8000>. الافتراضي قواعد محلية ولا يحتاج نموذجًا. تنشأ قاعدة البيانات في `data/accp.sqlite3` وتبقى مستثناة من Git. لا تعرض الخدمة أو قاعدة البيانات أو رمز الجلسة على شبكة عامة.

## التشغيل المحلي — Windows PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.rag --reindex
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

إذا منع PowerShell تفعيل البيئة، اسمح بها لهذه النافذة فقط عبر `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned`. لا يلزم ملف أسرار أو مفتاح API للتشغيل بالقواعد.

## Ollama المحلي اختياري

النموذج المستهدف في `.env.example` هو `Jais-3-3.7B-GGUF:Q4_K_M`، وإعداد Ollama المطلوب `OLLAMA_REASONING_EFFORT=none` والمهلة 120 ثانية. يبقى المزود `rules` افتراضيًا. لتجربة Ollama يجب تثبيت النموذج والتحقق من ظهوره في `ollama list`، ثم ضبط `MODEL_PROVIDER=ollama` و`MODEL_BASE_URL=http://127.0.0.1:11434/v1` واسم النموذج المحلي الفعلي. التفاصيل والأوامر في [`docs/PROVIDER_SETUP_AR.md`](docs/PROVIDER_SETUP_AR.md) و[`Modelfile.jais`](Modelfile.jais).

موافقة إرسال الرسالة للنموذج تُطلب لكل إرسال، وموافقة السياق السابق منفصلة. عند تهيئة Ollama يظهر أيضًا خيار موافقة مستقل لهذه الجلسة لصياغة أسئلة متابعة مرنة باللهجة الأردنية باستخدام هدف الخانة وسبب السؤال والخصائص التصنيفية؛ لا يرسل هذا المسار نصوص الرسائل أو اقتباساتها. يحدد محرك القواعد الخانة التالية لأجل سلامة التغطية، بينما يصوغ النموذج السؤال حول الجزء الناقص بدل نسخ نص ثابت. إذا رفض المدقق اقتراحه، يعود التطبيق لصياغة القواعد. اختبارات Ollama الوهمية لا تثبت اتصالًا حيًا أو جودة الأسئلة على نموذج فعلي.

## الاختبارات وCI

الاختبارات لا تحتاج نموذجًا حقيقيًا. يتطلب اختبار المتصفح Chromium:

```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m compileall app scripts tests
node --check static/app.js
python -m app.rag --reindex
python -m pytest -q --ignore=tests/test_browser.py
```

إذا كان Playwright وChromium متاحين، شغّل المجموعة كاملة بـ`python -m pytest -q`. الاختبارات والمجموعات الاصطناعية ليست مراجعة بشرية مستقلة ولا تقييمًا حيًا لـOllama.

## قاعدة المعرفة

تتضمن قاعدة المصادر بيانات حكومية إقليمية، منها سجل لقانون الجرائم الإلكترونية الأردني رقم 17 لسنة 2023. تسجل الجغرافيا والنطاق والرابط ومقتطفات المصدر؛ المعلومات التشريعية هنا عامة ومحدودة وليست تكييفًا أو نصيحة لحالة فردية. الأمر:

```bash
python -m app.rag --reindex
```

يتحقق من corpus ويعيد تحميل JSON؛ الاسترجاع lexical محدود وليس بديلًا عن مراجعة المصادر أو تقييم الصلة المستقل.

## الملفات الأساسية

```text
app/core.py                 المقابلة والقواعد والفرز والتقرير
app/main.py                 FastAPI ومسارات الجلسة والموافقات المحلية
app/model.py                Ollama المحلي، الاستخراج والتحقق وصياغة الأسئلة
app/conversation.py         تحليل أهداف الرسائل وسياقها
app/fields.py               مخطط الحقول وأنواعها ومراسيها
app/rag.py                  استرجاع محلي ومقتطفات وامتناع عند ضعف الصلة
app/store.py                SQLite ورموز الجلسة والتحقق من الإصدار
static/                      واجهة عربية RTL
Modelfile.jais               إعداد نموذج محلي اختياري
scripts/                     تشخيص وتقييم اصطناعي
 tests/                      اختبارات القواعد وAPI والنموذج الوهمي والمتصفح
```

لا يشمل هذا النموذج الأولي تقييمًا إحصائيًا مستقلًا أو مراجعة مختصين أو اختبار اختراق أو اعتماد تشغيل متعدد المستخدمين. استخدم بيانات اصطناعية فقط إلى حين استكمال هذه الضوابط.
