# ACCP.AI — نموذج أولي عربي لمقابلة الوقائع الإلكترونية

تطبيق ويب عربي RTL لتسجيل إفادة عن واقعة رقمية، وطرح سؤال واحد ملائم في كل مرة، وحفظ الإجابات مع الاقتباسات ومصدرها، وإظهار فرز أولي قابل للتفسير، ثم إنشاء ملخص يراجعه المستخدم ويؤكده.

> **تنبيه:** هذا نموذج أولي للتجربة، وليس خدمة طوارئ أو مشورة قانونية أو بلاغًا رسميًا. درجات الفرز قواعد تجريبية وليست احتمالات أو إثباتًا. لا تستخدمه لحالات حقيقية عالية الحساسية أو نشر عام دون مراجعة وأمن واعتماد مناسب.

## ما يتضمنه هذا الفرع

- واجهة RTL عربية متجاوبة، مقابلة تكيفية، حفظ/استكمال، مراجعة وتصحيح/إضافة الوقائع، تأكيد إصدار محدد، وتنزيل Markdown.
- حالات متميزة للإفادة، النفي، عدم المعرفة، عدم التذكر، الامتناع، والتعارض. لا يُستنتج نشر الصور من مجرد التهديد به، ولا اختراق الحساب الأصلي من وجود حساب منتحل.
- SQLite محلي مع رمز منفصل لكل جلسة و`expected_revision` لمنع الكتابة على إصدار قديم.
- استرجاع معجمي محلي من قاعدة مصدر مصنفة جغرافيًا تشمل مصادر أسترالية (`AU`)، والولايات المتحدة (`US`)، والأردن (`JO`). قوائم البلدان وخياراتها تُشتق من قاعدة المصادر نفسها.
- جواب RAG يعرض مقتطف المصدر المسترجع نفسه مع بياناته؛ يستبعد النظام الأسئلة الضعيفة أو غير المطابقة بدل توسيع النتيجة بتشابه لفظي واحد.
- الوضع الافتراضي محلي ولا يحتاج مفتاحًا. مزود OpenAI-compatible اختياري يتطلب موافقة مستقلة لكل إرسال. في وضع السؤال يُرسل السؤال الحالي والمقتطفات المختارة؛ وفي وضع المقابلة يُرسل نص الرسالة الحالية فقط لاستخراج حقائق منظمة. لا يُرسل سجل المحادثة أو رمز الجلسة أو حقائق سابقة تلقائيًا.

القيود المعمارية في [`docs/HANDOFF_AR.md`](docs/HANDOFF_AR.md)، سياسة الفرز التجريبية في [`docs/POLICY_AR.md`](docs/POLICY_AR.md)، وسجل التحقق وحدوده في [`docs/VALIDATION_AR.md`](docs/VALIDATION_AR.md).

## التشغيل المحلي — Linux/macOS

يتطلب Python 3.10 أو أحدث. من مجلد المستودع:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
set -a
. ./.env
set +a
python -m app.rag --reindex
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

افتح <http://127.0.0.1:8000>. الافتراضي قواعد محلية ولا يحتاج إلى مفتاح. تنشأ قاعدة البيانات تلقائيًا في `data/accp.sqlite3`؛ الملف مستثنى من Git لأنه قد يحوي بيانات شخصية. لا تعرض الخدمة على شبكة عامة ولا تشارك قاعدة البيانات أو رمز الجلسة. لا تشغّلها على `0.0.0.0` دون بوابة وصول ومصادقة وTLS وسياسة بيانات.

## تشغيل محلي نظيف على Windows PowerShell

من جذر المشروع في PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.rag --reindex
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

إذا منع PowerShell تفعيل البيئة بسبب سياسة السكربتات، اسمح بها لهذه النافذة فقط ثم أعد التفعيل:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```

لا يلزم ملف `.env` أو مفتاح API للتشغيل المحلي. لا تضع أسرارًا في أوامر محفوظة أو Git.

## مزود النموذج الخارجي الاختياري

يبقى `MODEL_PROVIDER=rules` هو الافتراضي. بعد مراجعة سياسة الاحتفاظ لدى المزود، اضبط البيئة عبر وسيلة إدارة أسرار محلية، مثل:

```bash
MODEL_PROVIDER=openai-compatible
MODEL_BASE_URL=https://api.openai.com/v1
MODEL_NAME=gpt-4o-mini
MODEL_API_KEY=...       # سر للمشغّل؛ لا تضفه إلى Git أو الواجهة
MODEL_TIMEOUT_SECONDS=15
```

لا يظهر خيار الموافقة إلا إذا كان المزود مضبوطًا. في وضع السؤال، يرسل الخيار نص السؤال الحالي والمقتطفات المحلية المختارة فقط. وفي وضع المقابلة، الخيار الأول يسمح بإرسال نص الرسالة الحالية فقط؛ إرسال السياق السابق يتطلب مربع موافقة منفصلًا اختياريًا، غير محدد افتراضيًا، وحده 4500 حرف ويشمل حتى أربع عناصر رسائل حديثة (منها السؤال المعلق)، وعشر حقائق وأربعة أحداث مالية ذات صلة. لا يرسل سجل الجلسة كاملًا أو معرّفها أو رمزها. أي معلومة شخصية يكتبها المستخدم في الرسالة الحالية تدخل ضمن ما وافق على إرساله. الموافقات مؤقتة لهذا الطلب، وفشل المزود يعود إلى القواعد أو جواب RAG المحلي. الاختبارات تستخدم مزودًا وهميًا، ولم تُجرَ مكالمة إنتاج حقيقية في هذا الفرع.

## الاختبارات وCI

الاختبارات الوحدوية وAPI لا تتطلب نموذجًا حقيقيًا. يتطلب اختبار المتصفح Chromium، ويستخدم تطبيقًا محليًا وبيانات اصطناعية:

```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m unittest discover -s tests -v
node --check static/app.js
```

في Ubuntu يمكن استخدام `python -m playwright install --with-deps chromium`. سير عمل GitHub Actions يشغل فحوصات Python/JavaScript، وصحة قاعدة المصادر، واختبارات القواعد وAPI والتزامن والمزود الوهمي والمتصفح عند كل `push` و`pull_request`.

يوثق [`docs/CONVERSATION_V2_AR.md`](docs/CONVERSATION_V2_AR.md) تدفق الأهداف متعددة النوايا، نطاق السياق والموافقات، تعريف مقاييس المحادثة، نتائج المجموعات الاصطناعية، وأوامر Windows لتقييم القواعد أو Ollama. تشغيل النموذج من CLI يتطلب `--include-bounded-context` منفصلًا لإرسال سياق صناعي؛ الافتراضي يرسل الرسالة الحالية فقط.

## قاعدة المصادر

تضم قاعدة المعرفة الحالية مصادر حكومية موثقة من أستراليا والولايات المتحدة والأردن. وتُخزَّن الجغرافيا وتاريخ المصدر وتاريخ الإدخال وإصدار المحتوى والرابط ومقتطف المحتوى لكل سجل. تاريخ غير منشور صراحةً يبقى `null` بدل تخمينه. وجود مصدر أردني لا يعني وجود إرشاد لكل موضوع أو أن التطبيق قد قدّم بلاغًا؛ إذا غاب التطابق الملائم يمتنع النظام عن الإجابة المحلية.

عند صيانة `data/knowledge.json` افتح الصفحة الرسمية وتحقق من النطاق والنص والتاريخ، ثم حدّث إصدار corpus وأضف حالات اختبار إيجابية وسلبية قبل الدمج. الأمر:

```bash
python -m app.rag --reindex
```

يتحقق من الحقول والروابط وتكرار المعرّفات ويعيد قراءة JSON فقط؛ **لا** يبني فهرسًا دلاليًا أو embeddings. الاسترجاع الحالي lexical محدود وليس بديلًا عن مراجعة المصادر أو تقييم الصلة مستقلًا.

## الملفات الأساسية

```text
app/core.py               المقابلة، الاستخراج المحلي، الفرز والتقرير
app/main.py               FastAPI ونقاط الخدمة وترتيب الاستدعاءات الخارجية
app/model.py              مخطط الاستخراج والجواب الحرفي الاختياري والتحقق
app/conversation.py       تحليل أهداف الرسالة وبناء سياق محدود
app/rag.py                استرجاع محلي، مقتطفات، وامتناع عند ضعف الصلة
app/store.py              SQLite، رمز الجلسة، وتحقق الإصدار
static/                   واجهة عربية RTL وحالة طلب لكل جلسة
data/knowledge.json       قاعدة المصادر حسب الجغرافيا
scripts/evaluate_conversation_v2.py  تقييم القواعد/النموذج متعدد الجولات
tests/                    اختبارات القواعد، API، التزامن، النموذج الوهمي والمتصفح
.github/workflows/tests.yml  تشغيل CI
```

هذه نسخة أولية لا تشمل تقييمًا إحصائيًا مستقلًا، مراجعة سلامة مختصين، مراجعة قانونية، اختبار اختراق أو تشغيلًا متعدد المستخدمين. يلزم ذلك قبل استخدام إفادات حقيقية.
