# دليل التسليم — ACCP.AI

**الغرض:** نموذج أولي قابل للتشغيل محليًا لالتقاط إفادة عربية عن واقعة إلكترونية، إجراء مقابلة تكيفية، حفظ مصادر الحقول، وعرض تقرير للمراجعة. بُني هذا العمل على فرع `feature/accp-delivery-ready` لأن مستودع GitHub كان فارغًا بلا commits أو فرع افتراضي وقت البدء؛ ولم تكن هناك واجهة ASP.NET أو خدمة قائمة يمكن ربطها.

## المعمارية ومسؤولية المكوّنات

- `static/index.html`, `static/style.css`, `static/app.js`: تطبيق واجهة RTL عربية في المتصفح؛ اختيار/إنشاء جلسة، سؤال واحد، وضع منفصل للسؤال والإرشاد، إيقاف/استكمال، اختيار الاختصاص، مراجعة الحالة، تأكيد الإصدار، وتنزيل Markdown. تستخدم `textContent` لعرض الرسائل بدل تفسيرها كـ HTML.
- `app/main.py`: خدمة FastAPI، توثيق OpenAPI، تقديم الملفات الثابتة، نقاط API للجلسات والرسائل/الأسئلة/الاختصاص/الاستكمال/التأكيد والتقرير، والتحقق من رمز الحالة وإصدارها.
- `app/core.py`: نموذج المجال، استخراج القواعد، إسناد كل حقل لاقتباس ورسالة/سؤال ووقت، التعامل مع عدم المعرفة والتعارض والتصحيح، اختيار الحقل التالي، سياسة الفرز، وعرض التقرير.
- `app/store.py`: تخزين SQLite محلي، رمز عشوائي مستقل لكل جلسة كـ bearer capability، وقفل/معاملة SQLite مع فحص `expected_revision` لمنع الكتابة فوق نسخة أحدث.
- `app/rag.py` و`data/knowledge.json`: استرجاع معجمي محلي من نصوص مصادر مختصرة مصنفة حسب الاختصاص، وتوليد جواب محلي مع الاستشهادات أو الامتناع عن الإجابة عند نقص الصلة.
- `app/model.py`: موائم اختياري لمزود OpenAI-compatible؛ لا يستقبل إلا السؤال الحالي والمصادر المرتبطة به عندما يكون المزود مضبوطًا، ويعيد `None` عند فشل الشبكة ليستخدم التطبيق الرد المحلي.
- `tests/`: اختبارات قواعد ومخزن وAPI وموائم النموذج الوهمي. لا يحتاج تشغيلها إلى مفتاح API أو اتصال بمزود خارجي.

## رحلة الطلب والبيانات

1. ينشئ المتصفح جلسة عبر `POST /api/sessions`، ويحفظ رمز دخول خاصًا بها في `localStorage`. لا يُعاد الرمز في مسارات القراءة العامة؛ يجب إرسال `X-Case-Token` لقراءة الجلسة أو تعديلها.
2. كل إجابة تمر عبر الواجهة إلى FastAPI، ثم إلى المقابلة في `core.py`، وبعدها تُحفظ الحالة ورسائل الحوار معًا في معاملة SQLite واحدة. إذا أُرسل إصدار قديم، تُعاد `409` ولا تُكتب الحالة القديمة.
3. يستخرج المحلل معلومات معروفة من كل رسالة ويحتفظ بالعبارة الأصلية ومرجع الرسالة ومرجع السؤال والوقت. الأجوبة القصيرة مثل «نعم/لا» تبقى منسوبة للسؤال السابق. تُعامل المبالغ المطلوبة والمدفوعة، ووقت البداية وأحدث تواصل، والتهديد بالنشر وحدوثه، ومعرّف التواصل والهوية كحقول منفصلة.
4. يعرض النظام سؤالًا واحدًا عن أولوية الحقول المفقودة. تظهر السلامة أولًا عند وجود تهديد، وتؤدي إشارة خطر مباشر جديدة أثناء الإجابة العادية إلى توقف سلامة وإعادة تقييم. وفي وضع السؤال تتجاوز رسائل الخطر المباشر الصريحة عالية الثقة RAG ومزود النموذج.
5. وضع «سؤال للبوت» يسترجع مصادر مناسبة للاختصاص المختار. لا يُرسل سجل المقابلة إلى الاسترجاع أو النموذج الاختياري. إذا وافق المستخدم لكل سؤال، يُرسل نص السؤال الحالي ومقتطفات المصدر فقط؛ التفاصيل الشخصية المكتوبة داخل السؤال نفسه ستكون ضمن الطلب الخارجي.
6. التأكيد مربوط بإصدار/ملخص محدد؛ رسالة تُغير الوقائع تزيل التأكيد. التقرير يضم ما هو معلوم ومصدره، ما ينقص، أسباب الفرز وحدوده، وأي إحالات عرضت للمستخدم.

## الخصوصية والأمن — قيود النموذج الأولي

- التشغيل الافتراضي محلي، وقاعدة `data/accp.sqlite3` لا تُرفع إلى Git. مع ذلك SQLite غير مشفر افتراضيًا، ورمز الجلسة في `localStorage` غير محمي من مستخدم الجهاز نفسه أو سكربت خبيث؛ استخدم بيانات تركيبية للتجربة، ولا تستعمل جهازًا مشتركًا أو خدمة عامة.
- رمز الجلسة يعمل كـ bearer token. لا يوجد نظام حسابات، أو تسجيل دخول، أو أدوار، أو نقل جلسة بين أجهزة، أو حماية نشر multi-tenant، أو حذف جلسة من الواجهة. وجود UUID وحده غير كافٍ للوصول لكن من يملك الرمز يستطيع الوصول. حماية بيانات الإنتاج تتطلب مصادقة وهوية، نقل HTTPS، تشفيرًا وإدارة مفاتيح، سياسة احتفاظ وحذف، تدقيقًا أمنيًا، وحدود طلبات.
- لا يُخزّن التطبيق صورًا أو تسجيلات أو مرفقات، ولا يفحص الأدلة، ولا يقدم وظيفة بلاغ أو إخطار. النص لا يستنتج وجود أو سلامة ملف لم يُرفع.
- لا تضبط مضيفًا عامًا على `0.0.0.0` قبل إنشاء بوابة وصول وTLS وسياسة بيانات وتحديد صلاحيات. الإعداد الآمن للتجربة هو `127.0.0.1`.
- خيار النموذج الخارجي معطل افتراضيًا ولا يظهر دون المتغيرات اللازمة. فشل الشبكة لا يمحو نص المستخدم؛ واجهة الإرسال تعيد قراءة الحالة قبل اقتراح إعادة الإرسال. اختبارات النموذج الحالية تستخدم مزودًا وهميًا، ولم تُجرَ مكالمة فعلية.

## التشغيل

من جذر المشروع، Python 3.10 أو أحدث:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
set -a; . ./.env; set +a
python -m app.rag --reindex
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

افتح <http://127.0.0.1:8000>. يتكون SQLite تلقائيًا من `ACCP_DB_PATH` (افتراضيًا `data/accp.sqlite3`). لعرض آمن استخدم جلسة تركيبية:

1. ابدأ جلسة جديدة واكتب إفادة قصيرة عن تهديد واتساب.
2. أجب عن السلامة «لا» ثم صف التهديد، وأكمل سؤالًا واحدًا في كل مرة.
3. لاحظ أن المطلوب والمدفوع منفصلان، وأن الدفع وحده لا يثبت مهلة أو نشرًا.
4. استخدم سؤالًا موجّهًا في «وضع السؤال للبوت» واختر `AU` أو `US` قبل طلب نصيحة محلية؛ جرّب الاختصاص الفارغ و`JO` لتلاحظ الامتناع عن المصدر المحلي.
5. احفظ الجلسة واستكملها، ثم راجع الوقائع وصححها/أضفها، أكّد الإصدار ونزّل التقرير.
6. إذا ظهرت عبارة خطر مباشر أثناء مقابلة لاحقة، يجب أن يتوقف المسار العادي وتظهر رسالة سلامة عامة.

## إعداد النموذج الاختياري

انسخ `.env.example` إلى `.env` واضبط `MODEL_PROVIDER=openai-compatible` و`MODEL_API_KEY` و`MODEL_BASE_URL` و`MODEL_NAME` و`MODEL_TIMEOUT_SECONDS`. لا تضع سرًا في Git. لا يُرسل الطلب إلا بعد موافقة واضحة لكل سؤال من الواجهة. الرد يُعرض مع ملاحظة أنه صياغة مزود خارجي؛ تبقى أرقام الاستشهادات محصورة في المصادر المسترجعة. لم تُختبر خدمة حقيقية في هذه المهمة، ولا يوجد مفتاح اختباري مستخدم.

## قاعدة المصادر وتحديثها

يحتوي `data/knowledge.json` على الملخصات وعنوان كل صفحة وجهة النشر والرابط وتاريخ المصدر وتاريخ الإدخال والجغرافيا وإصدار المحتوى. المصادر الحالية:

1. [eSafety — How to collect evidence](https://www.esafety.gov.au/report/how-to-collect-evidence) — الحكومة الأسترالية، AU، آخر تحديث مسجل 2026-05-14.
2. [eSafety — Report image-based abuse](https://www.esafety.gov.au/key-topics/image-based-abuse/report-image-based-abuse) — الحكومة الأسترالية، AU، آخر تحديث مسجل 2026-01-02.
3. [FTC — What To Do if You Were Scammed](https://consumer.ftc.gov/articles/what-do-if-you-were-scammed) — الولايات المتحدة، US، آخر تحديث مسجل 2026-06.

هذه إرشادات رسمية عامة داخل نطاقها الجغرافي، وليست دليلًا على حالة مستخدم. لا توجد حاليًا مصادر محلية للأردن. أعد فتح صفحات الجهات للتحقق من صحتها وتواريخها قبل إضافة معلومات جديدة. بعد التعديل:

```bash
python -m app.rag --reindex
python -m unittest discover -s tests -v
```

`--reindex` يتحقق من البنية والحقول المطلوبة؛ لا ينشئ embeddings. الاسترجاع lexical بسيط مع تطبيع محدود للبادئات العربية. إذا كان السؤال غير مطابق أو الاختصاص غير مدعوم، يعرض التطبيق غياب مصدر بدل رابط غير ذي صلة. أضف اختبارًا لاسترجاع المصدر الصحيح والاستشهاد وحدوده قبل دمج أي مصدر جديد.

## التقييم والاختبارات

- السياسة التجريبية `ACCP-TRIAGE-0.1.0` موثقة في [`POLICY_AR.md`](POLICY_AR.md). تعرض الدرجة كأولوية مراجعة لا كنسبة احتمال، وتستخدم أعلى قاعدة واحدة.
- الاختبارات اصطناعية وقطعية؛ تغطي سيناريو الحالة، خطأ الإجابة غير المباشرة، حالات عدم المعرفة والتذكر، المبالغ المتمايزة، الفروع الحرجة للسلامة، الاستخراج والانتحال، الحدود الجغرافية للمصادر، وصول الجلسة، الاستكمال، التأكيد والتصحيح، الخطأ الوهمي للمزود، والطلبات القديمة.
- لم تُنفذ مجموعة تقييم مستقلة ممثلة للمستخدمين، ولا قياسات Precision/Recall أو جودة اللهجات أو زمن استجابة خدمة حقيقية، ولا اختبار تحميل/أمان أو متصفح آلي. لا يوجد مقياس معايرة أو دليل اعتماد مختصين. انظر [`VALIDATION_AR.md`](VALIDATION_AR.md) لنتيجة التشغيل الفعلية وحدودها.

## مشاكل معروفة والعمل اللاحق

1. محلل القواعد ليس نموذج لغة ولا محللًا لغويًا شاملًا؛ يحتاج اختبارات أوسع للهجات، والإملاء، والنفي والسياق، ويجب ألا يُستخدم كأنه يثبت الوقائع.
2. اختبار الواجهة الحالية عبر API/HTTPX وليس متصفحًا آليًا حقيقيًا. أضف Playwright smoke test قبل أي إصدار مُستضاف.
3. مصادقة رمز الجلسة مناسبة للتجربة الفردية فقط. خدمة متعددة المستخدمين تحتاج حسابات وملكية وCSRF/CORS/HTTPS وسياسة حفظ وحذف ومراجعة تهديدات.
4. لا يوجد رفع ملفات أو تحليل أدلة أو إرسال بلاغات أو ربط طوارئ؛ الرسائل العامة لا تحدد رقمًا محليًا.
5. قاعدة المعرفة صغيرة، وبعض الاختصاصات غير مدعومة، ولا يوجد تحديث مجدول أو بحث قانوني آلي. مراجعة بشرية لكل محتوى جديد مطلوبة.
6. لم يُشغّل نموذج خارجي حقيقي ولم تُقاس موثوقية الردود أو سياسات احتفاظه.
7. التقرير Markdown فقط. لا يوجد PDF/طباعة مهيئة أو اعتماد توقيع رقمي.
8. مراجعة مختصين مستقلين للسياسة وخصوصية البيانات والاستخراج والتجربة مطلوبة قبل الاستخدام مع إفادات حقيقية.
