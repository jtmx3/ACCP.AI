# سجل التحقق والجاهزية

**آخر تشغيل:** 2026-11-03 في Sandbox (Python 3.12 وChromium/Playwright). البيانات المستخدمة في التقييم الاصطناعي فقط. جرى كذلك تشغيل مزود خارجي فعلي للنموذج؛ لا يحمل أي من النتائج معنى اعتماد أمني أو قانوني أو سلامة إنتاجية.

## نتائج التحقق الفعلية

| الفحص | النتيجة |
|---|---|
| `python3 -m compileall -q app scripts tests` | نجاح؛ ملفات Python قابلة للترجمة. |
| `node --check static/app.js` | نجاح؛ لا خطأ نحوي في JavaScript. |
| `git diff --check` | نجاح؛ لا مسافات/أخطاء تنسيق في التغييرات. |
| `python3 -m unittest discover -s tests -v` | **66/66 اختبارًا ناجحًا**، بما فيها API وSQLite وPlaywright واختبارات حواجز دمج النموذج. |
| تقييم القواعد `--mode rules` على `ACCP-SYNTH-AR-01` v2 | **21/21**، صفر إخفاق توقعات، وصفر استدعاءات نموذج. وسيط زمن الحالة 23.624 مللي ثانية؛ P95 = 47.865 مللي ثانية. |
| فحص المزود الحقيقي | إعداد OpenAI-compatible مكتمل؛ الخدمة قابلة للوصول؛ النموذج `gpt-6-luna` متاح؛ اختبار توليد JSON الثابت نجح في 1,710.12 مللي ثانية. |
| تقييم النموذج الحقيقي على المجموعة نفسها | **21/21 للمسار المتكامل** مع قواعد الرجوع؛ **5/21 فقط للنموذج بمعيار صارم**. 76 استدعاءً، 60 نتيجة مقبولة و16 مرفوضة (`schema_rejected`) مع الرجوع للقواعد. لم يُحسب أي نجاح رجوع نجاحًا للنموذج. وسيط زمن المزود 3,475.872 مللي ثانية؛ P95 = 5,596.051 مللي ثانية. |

### التمييز بين النتيجة المتكاملة والنموذج وحده

نجاح 21/21 يصف النظام المتكامل: القواعد المحلية تحقق الوقائع عندما تكون مخرجات النموذج مرفوضة أو غير كافية. أما معيار النموذج الصارم فلا يحتسب الحالة نجاحًا إلا إذا اجتازت الحالة والحقائق المتوقعة التحقق من اقتراحات النموذج وحدها من دون fallback داخل الحالة؛ نتيجته الفعلية **5/21**. لذلك لا تُفسر نتيجة النظام المتكامل على أنها دقة للنموذج.

نجحت فحوص الاتصال والتوليد والتقييم على **مزود خارجي** من بيئة Sandbox، لا على Ollama محلي. لم يكن Ollama مثبتًا أو متاحًا على `127.0.0.1:11434` في هذه البيئة. خطوات Windows موثقة في [`PROVIDER_SETUP_AR.md`](PROVIDER_SETUP_AR.md)، لكنها لم تُنفذ على جهاز Windows للمستخدم.

## ما تغطيه مجموعة التطوير

- **حواجز النموذج والخصوصية:** فصل تهيئة المزود واتصال الخدمة وتوافر النموذج والتوليد؛ إخفاء الأسرار؛ اختبار طلب الاستخراج على الرسالة الحالية والخانة المعلقة فقط؛ رفض الاقتباس غير المطابق والقيمة غير المسندة والحقول خارج المخطط.
- **دمج الحقائق الحساسة:** مبالغ الطلب/الدفع تمر عبر محلل علاقة الأحداث ولا تتجاوز توضيح التصحيح أو الإضافة؛ قناة عامة لا تصبح معرّف تواصل؛ طلب مال مكرر لا يصبح تهديدًا متكررًا؛ السرد اللاحق لا يخلق تعارضًا كاذبًا مع الإفادة الأصلية؛ ودفعة منفردة لا تجيب عن سؤال وصف الواقعة.
- **السلامة وسير المقابلة:** النفي والاقتباس والافتراض والخطر المباشر، عدم الخلط بين انتحال الهوية واختراق الحساب، مصدر كل معلومة، وعدم تكرار الأسئلة عن حقائق معروفة.
- **السؤال داخل المحادثة:** اختبار API على الاستفسار المحلي داخل وضع الإجابة، مع الرد ثم متابعة السؤال المعلّق دون تغيير يدوي للوضع.
- **التقرير والتنزيل:** JSON وMarkdown والواجهة تعرض الحالة والقيمة منفصلتين، والأسماء بالعربية، والمجهول والتعارض الفعلي وروابط المصدر والتوقيتين؛ ويتحقق الاختبار من تطابق النسخة المعروضة وحالة تأكيدها بعد التصحيح والتنزيل والطباعة.
- **واجهة التشغيل:** اختبار Chromium يميز مراحل المزود ويختبر fallback والتنزيل والطباعة. حالات لوحة الاتصال في اختبار المتصفح تستخدم API وهمية لضبط الحالات؛ ليست اختبار اتصال مزود حقيقي من المتصفح. استدعاء النموذج الحقيقي أُجري عبر مشغّل التقييم.
- **التزامن والحفظ:** اختبارات HTTP محلية لتعارض الإصدارات وحماية الرموز والرد المتأخر بين جلستين، وليست اختبار حمل أو نشر عام.

## الإخفاقات التي ظهرت أثناء التطوير

كشف التشغيل الأول للمزود الخارجي تعارضًا كاذبًا في مبلغ تالٍ وتمثيل القناة كمعرّف؛ وكشفت جولات التشخيص التالية التباس طلب المال المتكرر بالتهديد، وإكمال سؤال التفاصيل بدفعة شحن، وتعارض سرد لاحق مع الإفادة الأصلية. أضيفت قيود دلالية واختبارات تطوير مستقلة لهذه الحالات، ثم أُعيد تشغيل المجموعة الثابتة حتى اجتاز المسار المتكامل 21/21. ملفات التشخيص الأول والنهائي متاحة أعلاه. هذا سجل لتطور التنفيذ، وليس دليلًا على أن النموذج وحده صار موثوقًا؛ ما زال تقييمه الصارم 5/21.

## ما لم يُختبر — لا يُفهم على أنه اجتاز

- لا توجد مجموعة مستقلة ممثلة للمستخدمين أو مراجعة بشرية/خبيرة، ولا قياس Precision/Recall أو false-negative للخطر أو جودة اللهجات أو معايرة درجات الفرز.
- نتيجة النموذج الصارمة 5/21 منخفضة؛ لم تُثبت جودة الإرشاد أو RAG في تقييم منفصل، ولا ملاءمة النموذج للاستخدام في بلاغ حقيقي.
- لم يُشغّل Ollama محليًا على Windows ولم يُتحقق من سعة جهاز المستخدم. مزود Sandbox الخارجي لا يثبت زمن الشبكة أو الخصوصية أو توافر مزود آخر.
- ليس اختبار اختراق أو حمل/ضغط؛ ولا توجد مصادقة متعددة المستخدمين، أو تشفير قاعدة البيانات، أو سياسة احتفاظ وحذف، أو صلاحيات تشغيل إنتاجية.
- اختبارات Playwright وحالات provider-status الوهمية تبرهن سلوك الواجهة والـAPI في البيئة المحلية؛ لا تثبت تجربة نشر أو اتصال حقيقي من جهاز مستخدم.

**حالة المنتج:** نموذج أولي محلي للعرض والتجريب فقط. لا يقدم بلاغًا رسميًا ولا يحل محل جهة طوارئ أو مختص. يلزم تقييم مستقل ومراجعة السلامة والخصوصية والأمن قبل استخدامه مع إفادات حقيقية. راجع [`HANDOFF_AR.md`](HANDOFF_AR.md) و[`POLICY_AR.md`](POLICY_AR.md).
