# سجل التحقق والجاهزية

**البيئة:** Python 3.12 في Sandbox، قواعد SQLite مؤقتة، Chromium عبر Playwright، وحالات اختبار اصطناعية فقط. **مزود حقيقي:** غير مستخدم؛ فحوص الموائم تستخدم استجابات وهمية. لا يحمل سجل النجاح معنى اعتماد أمان أو سلامة.

## الأوامر والنتائج الفعلية

| الأمر/الفحص | النتيجة |
|---|---|
| `python3 -m compileall -q app tests` | نجاح؛ لا أخطاء bytecode في ملفات Python الحالية. |
| `node --check static/app.js` | نجاح؛ لا أخطاء نحوية في عميل المتصفح. |
| `python3 -m app.rag --reindex` | نجاح؛ تحقق من corpus `2026-11-03.3` و6 سجلات مصدر وبيانات scope/topics. لا ينشئ فهرسًا دلاليًا أو embeddings. |
| `python3 -m unittest discover -s tests -v` | نجاح: 48 اختبارًا، كلها `OK`. |
| تكرار `tests.test_browser.BrowserWorkflowTests.test_model_consent_is_optional_and_changes_scope_by_mode` خمس مرات | نجاح: 5/5، من دون `sleep` ثابت. |

تقسيم مجموعة الاختبارات الكاملة: 25 اختبار قواعد/سير عمل/RAG، و11 API وتزامن، و6 موائم نموذج باستجابات وهمية، و3 مخزن SQLite، و3 اختبارات Playwright فعلية عبر HTTP loopback.

## تغطية قابلة لإعادة الإنتاج

- **تأكيد الملخص:** إعادة إنتاج تأكيد الملخص ثم حفظ الجلسة واستئنافها وإضافة المبلغ المطلوب أثناء سؤال السلامة؛ يبطل التغيير التأكيد ويزيد إصدار الملخص، ويحفظ سجل التأكيد السابق. قراءة الحالة وتنزيل Markdown لا يعرضان نسخة معدلة على أنها مؤكدة. كما يغطي اختبارًا لحالة قديمة ذات digest غير مطابق.
- **السرد غير المصنف:** الكلمات التصنيفية المنفردة «ابتزاز» و«تهديد»، وصيغ أخرى مثل «احتيال إلكتروني» و«مضايقة»، تستدعي سؤالًا واحدًا مناسبًا بدل استنتاج تهديد أو درجة. وصف لا يتعرف على نوعه ينتقل إلى استيضاح «unclassified» ويبقى اكتماله دون 100% مع بيان الحاجة إلى مراجعة التصنيف.
- **الدفع والنفي:** يفصل الاختبار بين طلب الدفع الشرطي وبين دفع مكتمل، ويختبر النفي الملحق بحرف العطف، ونفي الدفع بلا طلب، والإثبات والتصحيح، وطلب 100/دفع 130 في رسالة واحدة. لا يُسجّل نص غير مالي بوصفه قيمة مبلغ.
- **سبب السؤال:** اختبار API للوضعين `answer` و`question` يثبت أن سؤال «ليش بتسأل عن الخطر؟» يُجاب عنه محليًا من سبب الخانة المعلقة، دون RAG أو مزود خارجي ودون تعديل الوقائع أو احتساب الاستفسار إجابة.
- **RAG:** الاقتصار على الاختصاص المحدد، تطابق عدة مفاهيم، مقطع ظاهر في الجواب والاستشهاد، الامتناع عن سؤال عام/ضعيف، ورفض صفحة وحدة الجرائم الإلكترونية الأردنية عند طلب خطوات حفظ الأدلة التي لا تقدمها. اختُبرت مصادر الشرطة الأردنية وJOCERT ورقم الطوارئ الأردني كلٌ بنطاق موضوعي مختلف.
- **موائم نموذج اختياري وهمي:** اقتباس حرفي من مصدر مختار، رفض نص حر أو اقتباس غير مطابق أو حقل غير مسموح أو مبلغ يخالف النص، وطلب استخراج يحوي الرسالة الحالية والخانة المعلقة دون سجل أو معرّف جلسة. اختبار timeout يعيد `None` للرجوع المحلي.
- **الموافقة في المتصفح:** دون موافقة لا يُستدعى موائم السؤال ولا `_chat`. مع الموافقة، يُعترض طلب المزود الوهمي ويُتحقق من أن الحمولة تحتوي السؤال الحالي ومقتطفات المصدر المختار فقط، لا سجل المقابلة؛ وتُصفّر خانة الموافقة بعد إتمام الطلب. نجح اختبارها 5/5 مرات متتالية.
- **التزامن:** استدعاء استخراجين في الوقت نفسه عبر جلستين، وكتابة جلسة أخرى أثناء انتظار مزود Q&A دون حجز قفل SQLite، ورفض نتيجة قديمة بعد تغير الإصدار مع عدم إعادة الطلب.
- **المتصفح الحقيقي:** مقابلة/حفظ/استكمال/تصحيح/تأكيد/تنزيل تقرير؛ وصول رد جلسة A متأخرًا بينما B نشطة حتى مع تساوي المراجعة مع بقاء الكتابة التالية موجهة إلى B؛ والموافقة غير محددة افتراضيًا ومحدودة لكل طلب ووضع.

## ما لم يُختبر — لا يُفهم على أنه اجتاز

- لا توجد مجموعة تقييم مستقلة ممثلة للمستخدمين، ولا قياس Precision/Recall أو false-negative للخطر أو زمن التوقف المبكر أو جودة اللهجات أو معايرة الدرجات.
- لم يُستخدم نموذج/مزود خارجي حقيقي؛ لا توجد قياسات latency أو rate/failure أو هلوسة أو سياسة احتفاظ فعلية. اختبارات المزود mocked فقط.
- اختبارات التزامن داخلية حتمية وبعدد جلسات محدود؛ ليست اختبار ضغط أو حمل أو ضمانًا لقاعدة بيانات إنتاج.
- لا يوجد اختبار اختراق أو مراجعة أمنية شاملة، ولا مصادقة متعددة المستخدمين، تشفير قاعدة بيانات، سياسة احتفاظ/حذف، أو إعداد نشر عام.
- لم يراجع مختص مستقل سياسة الفرز أو ملخصات المصادر أو تحويل القواعد إلى أسئلة؛ لا تستخدم النتائج لقرار قانوني أو تشغيلي.

**حالة المنتج:** نموذج أولي محلي اجتاز اختبارات حتمية وواجهة متصفح حقيقية أساسية. ليس خدمة طوارئ أو تقديم بلاغ، ولا منتجًا متعدد المستخدمين. يلزم تقييم مستقل ومراجعة السلامة والخصوصية والأمن قبل أي استعمال لإفادات حقيقية. راجع [`HANDOFF_AR.md`](HANDOFF_AR.md) و[`POLICY_AR.md`](POLICY_AR.md).
