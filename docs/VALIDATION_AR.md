# سجل التحقق والجاهزية

**البيئة:** Python 3.12 في Sandbox، قاعدة SQLite مؤقتة، Chromium عبر Playwright، حالات اختبار اصطناعية فقط. **مزود حقيقي:** غير مستخدم؛ فحوص الموائم تستخدم استجابات وهمية. لا يحمل سجل النجاح معنى اعتماد أمان أو سلامة.

## الأوامر والنتائج الفعلية

| الأمر/الفحص | النتيجة |
|---|---|
| `python3 -m compileall -q app tests` | نجاح؛ لا أخطاء bytecode في ملفات Python الحالية. |
| `node --check static/app.js` | نجاح؛ لا أخطاء نحوية في عميل المتصفح. |
| `python3 -m app.rag --reindex` | نجاح؛ تحقق من corpus `2026-11-03.3` و6 سجلات مصدر وبيانات scope/topics. لا ينشئ فهرسًا دلاليًا أو embeddings. |
| `python3 -m unittest discover -s tests -v` | نجاح: 41 اختبارًا، كلها `OK`. |

تقسيم الاختبارات: 21 اختبار قواعد/استرجاع، 8 API وتزامن، 6 موائم نموذج وهمي، 3 مخزن SQLite، و3 Playwright end-to-end على HTTP loopback.

## تغطية قابلة لإعادة الإنتاج

- الحالات العربية: النفي والتهديد والتكرار، تمييز التواصل المتكرر عن الضرر، فحص خطر مباشر أثناء مراحل مختلفة، تعبيرات مقتبسة/افتراضية ومنفية، حساب منتحل دون استنتاج اختراق، ودليل غير موجود دون اختلاق حيازته.
- الأسئلة التكيفية: إظهار الحقول ذات الصلة، عدم سؤال الدفع/النشر في واقعة غير مالية/غير مرتبطة، فصل المطلوب عن المدفوع، حالات عدم المعرفة والتذكر والرفض، استيضاح واحد والتعارض وتصحيح محفوظ التاريخ.
- السياسة: فروق قواعد الأولوية 100/95/90/85، ورفض رسالة المستخدم التي تطلب رقمًا أو تأكيدًا غير مستحق.
- RAG: الاقتصار على الاختصاص المحدد، تطابق عدة مفاهيم، مقتطف ظاهر في الجواب والاستشهاد، الامتناع عن سؤال عام/ضعيف، ورفض صفحة وحدة الجرائم الإلكترونية الأردنية عند طلب خطوات حفظ الأدلة التي لا تقدمها. اختُبرت مصادر الشرطة الأردنية، وJOCERT، ورقم الطوارئ الأردني كلٌ بنطاق موضوعي مختلف.
- نموذج اختياري وهمي: اقتباس حرفي من مصدر مختار، رفض نص حر أو اقتباس غير مطابق أو حقل غير مسموح أو مبلغ يخالف النص، وطلب استخراج يحوي الرسالة الحالية والخانة المعلقة دون سجل أو معرّف جلسة. اختبار timeout يعيد `None` للرجوع المحلي.
- التزامن: استدعاء استخراجين في الوقت نفسه عبر جلستين، كتابة جلسة أخرى أثناء انتظار مزود Q&A دون حجز قفل SQLite، ورفض نتيجة قديمة بعد تغير الإصدار مع عدم إعادة الطلب.
- المتصفح الحقيقي: مقابلة/حفظ/استكمال/تصحيح/تأكيد/تنزيل تقرير؛ وصول رد جلسة A متأخرًا بينما B نشطة حتى مع تساوي المراجعة مع بقاء الكتابة التالية موجهة إلى B؛ وخيارات الموافقة غير المحددة افتراضيًا مع اختلاف البيانات المسموح بها بين وضع المقابلة ووضع السؤال.

## ما لم يُختبر — لا يُفهم على أنه اجتاز

- لا توجد مجموعة تقييم مستقلة ممثلة للمستخدمين، ولا قياس Precision/Recall أو false-negative للخطر أو زمن التوقف المبكر أو جودة اللهجات أو معايرة الدرجات.
- لم يُستخدم نموذج/مزود خارجي حقيقي؛ لا توجد قياسات latency أو rate/failure أو هلوسة أو سياسة احتفاظ فعلية. اختبارات المزود mocked فقط.
- اختبارات التزامن داخلية حتمية وبعدد جلسات محدود؛ ليست اختبار ضغط أو حمل أو ضمانًا لقاعدة بيانات إنتاج.
- لا يوجد اختبار اختراق أو مراجعة أمنية شاملة، ولا مصادقة متعددة المستخدمين، تشفير قاعدة بيانات، سياسة احتفاظ/حذف، أو إعداد نشر عام.
- لم يراجع مختص مستقل سياسة الفرز أو ملخصات المصادر أو تحويل القواعد إلى أسئلة؛ لا تستخدم النتائج لقرار قانوني أو تشغيلي.

**حالة المنتج:** نموذج أولي محلي اجتاز اختبارات حتمية وواجهة متصفح حقيقية أساسية. ليس خدمة طوارئ أو تقديم بلاغ، ولا منتجًا متعدد المستخدمين. يلزم تقييم مستقل ومراجعة السلامة والخصوصية والأمن قبل أي استعمال لإفادات حقيقية. راجع [`HANDOFF_AR.md`](HANDOFF_AR.md) و[`POLICY_AR.md`](POLICY_AR.md).
