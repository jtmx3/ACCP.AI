# سجل التحقق والجاهزية

**البيئة:** Python 3.12 في Sandbox، FastAPI مع SQLite مؤقت لاختبارات API. **النموذج الخارجي:** غير موصول؛ اختباراته محاكاة محلية. **البيانات:** حالات اصطناعية فقط.

## الأوامر والنتائج الفعلية

| التحقق | النتيجة |
|---|---|
| `python3 -m unittest discover -s tests -v` | نجاح: 22 اختبارًا لقواعد المقابلة وAPI/HTTPX وSQLite وموائم المزود الوهمي. |
| `node --check static/app.js` | نجاح: لا أخطاء نحوية في الواجهة. |
| `python3 -m app.rag --reindex` | نجاح: corpus `2026-11-02.1` وبيانات المصادر الثلاثة صالحة. |
| استيراد `app.main` وفحص مسارات API | نجاح. |
| تشغيل `uvicorn` مؤقتًا على loopback | نجاح: health، تحميل HTML، إنشاء جلسة وقراءتها برمزها، ثم إفصاح خطر مباشر في وضع السؤال؛ دخلت الحالة `urgent_stop` دون استدعاء RAG/المزود. أوقفت الخدمة وحذفت قاعدة smoke test المؤقتة. |

## ما غطته الاختبارات

- سيناريو المقابلة العربي: نفي الخطر المباشر، تفاصيل التهديد، بداية الواقعة وأحدث تواصل، التكرار، فصل المبلغ المطلوب عن المدفوع، وسيلة الدفع والمهلة، عدم معرفة ما إذا وقع النشر، الهوية/معرّف التواصل، والأدلة المذكورة.
- إجابة غير مباشرة عن مهلة الدفع مع محاولة توضيح واحدة؛ إذا بقي الحقل غير مجاب يتحول إلى `unresolved` لا إلى عدم معرفة أو نسيان أو رفض.
- أرقام عربية هندية/غربية، تعارض المبلغ المطلوب، عرض البدائل، منع التأكيد حتى الحل، حفظ سجل الاختيار/التصحيح، وإضافة تفاصيل بعد العرض.
- اقتباسات الحقول مرتبطة برسائل المستخدم وبالسؤال السابق عند وجود إجابة قصيرة. اختُبرت حالات تهديد دون استنتاج النشر، وحساب منتحل دون استنتاج اختراق الحساب الأصلي.
- خطر مباشر في البداية وأثناء المقابلة، وإفصاح خطر مباشر عالي الثقة في وضع السؤال يتجاوز RAG والمزود.
- قواعد الفرز الاصطناعية 95 و90 و85 و100، والتحقق من أن تعليمات المستخدم لا تفرض الدرجة أو التأكيد.
- استشهاد حسب الاختصاص، والامتناع عن سؤال غير ذي صلة أو اختصاص غير مدعوم.
- رفض الجلسة دون رمزها، استكمالها، رفض إصدار قديم، وعدم الكتابة فوق حالة أحدث.
- Timeout لمزود وهمي يرجع إلى الرد المحلي، وترشيح أرقام الاستشهادات التي لم يُرجعها الاسترجاع.

## لم يُنفذ — لا تُفسر على أنه اجتاز

- لا توجد مجموعة تقييم مستقلة؛ لم تُحسب Precision/Recall أو أخطاء النفي، false negatives للخطر، stop-early rate، جودة السؤال التالي، أو صحة الاستشهاد إحصائيًا.
- لا يوجد اختبار متصفح end-to-end آلي (Playwright/Selenium)، أو اختبار ضغط/تزامن متوازٍ، أو اختبار اختراق أو مراجعة أمان شاملة.
- لم يُضبط أو يُختبر مزود نموذج حقيقي؛ لا توجد قياسات لزمنه أو معدل فشله أو هلوسة/احتفاظه. الاختبارات خارجية غير متصلة ولا تستخدم سرًا.
- لم يراجع مختص مستقل سياسة الفرز أو يعايرها؛ لا تُستخدم في قرار قانوني أو تشغيلي.
- اللغة واللهجات مغطاة بعينة اصطناعية صغيرة وليست تقييمًا شاملًا للعربية.

**حالة المنتج:** نموذج أولي محلي اجتاز اختبارات قطعية وممر HTTP محدود، وليس منتجًا متعدد المستخدمين أو خدمة بلاغ/طوارئ. يلزم إكمال المراجعة البشرية والأمنية والتقييم المستقل قبل استخدام إفادات حقيقية. راجع [`HANDOFF_AR.md`](HANDOFF_AR.md).
